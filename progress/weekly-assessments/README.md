# Weekly Assessments & Retrospectives

Weekly reviews consolidate knowledge, ensure skills are genuinely retained, and verify that progress in the [Skill Matrix](../../roadmap/skill-matrix.md) is supported by concrete lab evidence.

---

## 📋 Weekly Review Template

```markdown
# Weekly Assessment: Week [XX] (YYYY-MM-DD to YYYY-MM-DD)

## 1. Quantitative Summary
- **Hours Invested**: XX / 21 Hours (3h/day target)
- **Labs Attempted**: XX
- **Labs Solved Independently**: XX
- **Case Studies Analyzed**: XX
- **New Skill Matrix Updates**: [List competencies upgraded]

## 2. Core Concepts Mastered
- [Concept 1]
- [Concept 2]

## 3. Persistent Blockers & Weak Points
- [Where did you struggle most? What took longer than expected?]

## 4. Retention Check
- Can I explain the root cause of this week's vulnerabilities without looking at notes?
- Can I write a minimal vulnerable vs secure code snippet from memory?

## 5. Adjustments for Next Week
- [Pacing adjustments, lab targets, or focus areas]
```
