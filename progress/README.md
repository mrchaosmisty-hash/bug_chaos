# Progress Tracking & Daily Execution System

Consistent daily practice and candid self-reflection are the engine of mastery in application security.

---

## 🎯 Tracking Structure

This directory tracks the learner's journey across two cadence levels:
1. **[`daily-log-template.md`](daily-log-template.md)**: Standard template for each 3-hour learning session.
2. **`logs/`**: Archive of individual daily learning logs (e.g., [`logs/day-001.md`](logs/day-001.md)).
3. **`weekly-assessments/`**: Weekly retrospectives reviewing knowledge retention, labs completed, and skill matrix updates.

---

## ⚖️ Rules for Logging Progress
- **Honesty First**: Documenting what failed or confused you is 10x more valuable than pretending an exercise was trivial.
- **Record Tested Hypotheses**: Always record *why* you tried a test, not just the command you ran.
- **Evidence-Based Completion**: Never claim a lab was solved without documenting the key request/response or error observed.
