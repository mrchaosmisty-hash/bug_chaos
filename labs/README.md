# Authorized Lab Exercises & Practice Documentation

This directory contains write-ups, proof-of-concept steps, and takeaways from authorized hands-on laboratory exercises.

---

## ⚖️ Rules of Engagement for Lab Work

1. **Authorized Environments Only**: Exercises documented here are conducted solely on designated training platforms (e.g., PortSwigger Web Security Academy) or isolated local containers (e.g., Dockerized OWASP Juice Shop, DVWA).
2. **Sanitize Captures**: Never include real session cookies, target credentials, or unredacted captures in repository files.
3. **Evidence-Based Documentation**: Do not mark labs as solved without recording the hypothesis tested and the actual proof of execution.

---

- **[`_template.md`](_template.md)**: Reusable write-up template for all lab exercises.
